# 镜头颜色匹配


执行具体方法前读取 [Craft 场景命令与参数](references/craft-methods.md)，按其中的对象选择、会话、输入替换和结果检查执行。

## 任务起点

先读取素材，确认交付用途、目标尺寸或时长、修改范围与必要格式。能从任务和素材确定的细节直接采用合理默认值；只询问会改变结果的缺失条件。

需要可见编辑器时交给 **filmcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/filmcraft-skills --skill filmcraft-editor`。当前新增技能为本地候选，发布前使用本地配套插件，不把此安装命令当作已发布证明。

## 执行步骤

1. 选参考镜头，先判断拍摄色彩与曝光差异。
2. 逐镜头校正黑白点和白平衡，再匹配中间调。
3. 最后加统一风格，避免用风格掩盖曝光问题。
4. 在相邻镜头间反复切换检查。

## 工具落地

使用 command_list 读取当前 Web 引擎命令；command_run 在可见页面执行，inspect 核对；open_file 导入素材，list_files 检查导出，save_project 或 save_file 写入工作区新路径。

先读取实际工具 schema，再填写参数；对象或文档 ID 使用返回值。查询到的命令必须在当前后端可用。保存前选择新输出路径，保留输入。需要的算法、格式或命令不存在时说明缺口，不能用相近名称冒充。

## 结果检查

- 肤色和中性物体不突变。
- 高光和暗部不过度截断。
- 保留逐镜头调整以便返工。

对照用户目标检查实际内容，而不只检查进程退出码。局部编辑查看局部细节，版式任务查看整页，时间媒体查看起止与关键段。异常结果先检查当前工程，避免重复执行不可逆操作。
