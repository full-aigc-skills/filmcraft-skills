# 完整任务编排任务模板

## 输入

素材路径与摘要、目标片长/帧率、字幕和音频要求、输出目录。确认当前授权范围及要保留的非目标内容；从本技能所在目录读取资源。

## 首次任务

示例请求：将已有镜头、配音和字幕组织为可重开的短片并交付成片。

分别核对素材、时间线、声音和字幕；按意图选择专业技能，多个阶段由本路由协调。本地示例 `examples/short-film.json` 用于理解参数与交接；先复制到工作目录并按真实素材、工程和对象调整，不把示例 ID 或规格套入用户工程。参数入口见 [本地命令参考](command-reference.md)。

## 失败

源摘要或素材缺失时停止依赖编辑；超时读取原任务证据，不重放。记录实际错误与阶段，结果 unknown 时先检查原工程和回执，不自动重放。安装诊断按需读取 [首次使用诊断](first-use-failures.md)。

## 局部修订

修订请求：替换一处镜头并保留音频、字幕和其余片段。核对预期源工程摘要，以新输出目录另存；原目标内复用已有授权，超出范围或授权约束变化才重新确认。

## 核验

工程重开、导出解码、目标修改与全部非目标保全。技术、创作和用户接受分别记录；缺少的维度标 NOT_RUN/manual_review，文件存在或目录检查不能替代验收。
