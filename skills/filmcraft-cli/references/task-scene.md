# 显式原生命令任务模板

## 输入

明确命令 ID、原参数、工程和选择上下文。确认当前授权范围及要保留的非目标内容；从本技能所在目录读取资源。

## 首次任务

示例请求：查询指定原生命令参数并在适用上下文同会话执行。

先 describe/check，再 run；业务意图明确时按专项技能处理。本地示例 `examples/commands-advanced.json` 用于理解参数与交接；先复制到工作目录并按真实素材、工程和对象调整，不把示例 ID 或规格套入用户工程。参数入口见 [本地命令参考](command-reference.md)。

## 失败

命令或参数不存在、上下文禁用时拒绝；不猜测原生对象 ID。记录实际错误与阶段，结果 unknown 时先检查原工程和回执，不自动重放。安装诊断按需读取 [首次使用诊断](first-use-failures.md)。

## 局部修订

修订请求：从配对返工示例理解结构，按真实对象和摘要生成新计划。核对预期源工程摘要，以新输出目录另存；原目标内复用已有授权，超出范围或授权约束变化才重新确认。

## 核验

逐步回执、保存重开、命令目标值与无关对象。技术、创作和用户接受分别记录；缺少的维度标 NOT_RUN/manual_review，文件存在或目录检查不能替代验收。
