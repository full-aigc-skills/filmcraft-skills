# 分层发行检查

源仓离线CI无条件执行 `python3 -I -B scripts/check_release.py --output REPORT_DIRECTORY`，输出逐测试结果、原始日志与文件摘要。元数据、单技能链接、共享资源同步、命令／场景目录、参数合同与入口测试均为必需检查，缺文件或失败不能被package条件跳过。

固定测试ID清单区分必需单元和需要原生环境的用例。必需单元必须PASS，环境用例缺条件时逐项NOT_RUN并保留原因；新增或变更的跳过未在清单声明时直接失败，删除环境用例也不能抹除记录。普通CI的绿色只表示离线门禁通过，不代表原生、宿主、目标平台、真实媒体或完整V1。

插件在独立仓库消费不可变标签与整树摘要；该仓库的CI另行验证固定源、插件元数据和固定公共协议映射。实际安装副本的冷启动、原生输出、headless／bridge与宿主发现仍须单独执行。源码、CI、固定安装、真实媒体、宿主及平台各自绑定版本与输入，不能把历史通过继承为当前组合通过。
