# PCM 包采样时序候选

技能源 dev.45 包含基于上游 `adfd9a66de2bebc764c7f57435ccdf0f1d2e1df6` 的累计 `0.2.0-craft.5` 候选补丁；现有不可变 craft.4 安装锁保持不变。

固定 dev.52 的真实媒体 VFR 探针保存、导出和解码通过，但音频相关性为 0.49865，低于 0.98 阈值；原生 PCM WAV 相关性也仅 0.47976，而独立 AAC 对照为 0.99987。44.1 kHz PCM 使用毫秒级 Matroska 时间戳时，包边界产生缺口或重叠。

候选在一个容器时间戳单位内按包内真实采样数累计位置，保留更大真实空隙。受检算术和采样帧对齐校验拒绝坏输入；其他编码路径不变，保留字幕、序列、音频精确时长及 Whisper 既有补丁。

本地 macOS arm64 回归：修复前连续采样用例失败、真实 100 ms 空隙用例通过；最终 3 项 PCM 用例和 43 项 codec 库回归通过。这不关闭 OpenSpec 9.32/9.33 或完整 V1。构建与真实媒体候选结果单独记录；该技能源发行不自动安装候选二进制。

构建入口为 `python3 -I -B scripts/build_pcm_runtime.py --repository <上游检出> --output <新私有目录> --target-directory <私有cargo目录>`。构建器核验固定提交与补丁摘要、执行相关回归、启用 Whisper 并生成版本绑定回执；Cargo 依赖须提前缓存，research 保持只读。
