# FilmCraft 时间变化素材的时间线验收

使用固定 FilmCraft 插件 dev.7／独立技能源 dev.6／原生 CLI 0.2.0-craft.1，不改变不可变发行内容。仅复制实际安装的时间线技能，在空目录自动安装其锁定原生运行时。

## 可观察行为

```mermaid
flowchart LR
    A[源素材：0–1 秒红色，1–2 秒绿色，2–3 秒蓝色] --> B[首镜头：源 0–1.5 秒]
    A --> C[未改镜头：源 2.5–3 秒，时间线 1.5 秒]
    B --> D[普通入点裁切：增加 0.5 秒]
    D --> E[首镜头移动到时间线 0 秒]
    E --> F[成片：红色、绿色、空白、蓝色]
    C --> F
```

首镜头保存重开后的 start 为 0、sourceIn 为 127008000000、duration 为 254016000000 ticks。第二镜头的原生检查对象不变，音轨和字幕记录不变，原交付全部文件摘要保持一致。PNG 预览与原生 MP4 解码分别核对 0.25 秒红色、0.75 秒绿色、1.25 秒黑色间隙及 1.75 秒蓝色，避免仅靠片段数量掩盖源入点错误。输出保留 24 帧及原生可编辑工程。

裁切 delta 使用数字类型时被拒绝，工作流要求十进制字符串 ticks。拒绝后没有成功 manifest，原工程保持不变。执行后全部 11 项原安装技能摘要仍匹配固定锁。
