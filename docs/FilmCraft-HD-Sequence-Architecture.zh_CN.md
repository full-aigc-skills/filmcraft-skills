# FilmCraft HD 序列架构

日期：2026-10-07。状态：当前独立技能源候选；固定插件发行保持不变。规格事实源为插件 `openspec/changes/establish-v1-plugin`，场景 FC-DM-001-HD、任务 4.44。本组件增量采用运行时与插件架构模式，不另建规格或产品基线。

## 驱动与实现位置

分段合同让五秒 1080p RGBA 序列无需扩大既有 v1 的 512 MiB 上限。首次使用分析发现，重复的 Python PNG 还原耗时较长。共享 `png_inspection.py` 现在逐行生成校验后的 RGBA8；Effect 的 `image_sequence.py` 与 Film 的 `sequence_assets.py` 使用这些行计算相同的像素摘要和真实 alpha 极值。各领域技能分别携带同步副本，单技能安装不依赖兄弟技能。

```mermaid
flowchart LR
    E[独立 Effect 导出技能] --> R[锁定原生渲染]
    R --> S[四个有界分段]
    S --> V[CRC 与 RGBA 像素校验]
    V --> F[独立 Film 素材技能]
    F --> C[连续原生序列]
    C --> M[原生工程与 MP4]
    M --> I[Pillow 与完整视频独立解码]
```

## 字节语义与资源边界

解码器继续只使用 Python 标准库。结构、CRC、有界解压和扫描数据长度校验在逐行还原之前执行。每行分派一次滤波器：None 直接复制；Sub 按通道模 256 还原；Up 使用相互隔离的 16 位整数槽位相加，通道之间不会进位；Average、Paeth 保留预测器和相等时的选择顺序。零残差快捷路径仍保留前一行依赖。独立构造的 PNG 用例覆盖五种滤波、溢出回绕、混合滤波和重复行。像素摘要、真实 alpha 极值仍为必需，文件名或清单声明不能替代解码。

每段解码量仍不超过 512 MiB；整体逻辑上限仍为 64 GiB／10,000 帧、编码总量 2 GiB。逻辑字节量不代表同时驻留内存。损坏像素、回执不匹配、范围错误和符号链接继续拒绝；优化没有改变预算和复用身份。

## 实际首次使用与证据

[HD 候选证据](evidence/effect-film-segment-hd-candidate-20261007.json) 绑定测试驱动、复制技能的全部文件和两个原生运行时摘要。测试仅复制一个 Effect 导出技能和一个 Film 素材技能至隔离 `.agents/skills`，从空的共享运行时开始，以公开 `workflow.py` 子进程和默认公开下载完成安装、使用，结束后核对技能保全。

| 核验 | 实测结果 |
| --- | --- |
| 原生输出 | 1920×1080、24 fps、五秒 |
| 序列 | 四段，120 帧 PNG 全部独立解码 |
| 逻辑 RGBA | 995,328,000 字节，超过旧的整序列上限 |
| Film 输出 | 原生 `.fcproj`；完整解码 120 帧 MP4；5.000000 秒 |
| 动画 | 标题像素由透明变为可见；八项合成像素核验 |
| 墙钟时间 | Effect 阶段 17.047 秒；完整冷启动候选 54.839 秒 |
| 默认测试 | Effect 51 通过／21 跳过；Film 52 通过／21 跳过；各两项滤波测试 |

单张原生 1080p 帧的还原由 2.028 秒降至 0.046 秒，RGBA 摘要一致。这是单帧测量，不是通用吞吐保证。首次完整 HD 分析运行被主动停止，不作为验收证据。Pillow、ffmpeg／ffprobe 是独立测试判据，不是新增解码器运行依赖。

## 失败、发行与剩余门禁

公开工作流仍须在安装前拒绝错误计划。分段恢复沿用项目／运行时绑定，复用前重新检查真实像素；失败或未完成的序列不能成为完整 Film 输入。当前 Art 候选回归覆盖十二帧、移动包后的文字修订、损坏分段拒绝和恢复，使用当前技能源，不证明 Art HD 首次使用。

任务 4.44 只关闭当前源码的 HD 优化与保全核验。不可变领域技能／插件发布、安装版 Art HD 编排、HD 文字返工／恢复及移动包仍在既有发行任务中待完成。已验证原生平台为 macOS arm64。模型调度、GUI、创作审批和完整 V1 验收保持开放。历史证据按版本保留，不覆盖旧记录。
