# FilmCraft 序列素材合同架构

## 事实源与阶段

既有 OpenSpec FC-DM-001-SEQUENCE 是事实源。本组件在独立技能源维护，并同步到十一项 Film 技能；插件技能快照尚未更新。当前仅完成清单验证与完整复制，不表示公开工作流导入、原生 CLI 冷安装或 Art 联调完成。

## 输入与校验

`sequence_assets.validate_sequence(path, digest)` 接收用户登记的 `sequence.json` 和 SHA-256，校验严格 `craft-image-sequence/v1` 字段集、归一有理帧率、整数帧数及对应时间基。只接受完整连续的 `frame_00000.png` 编号帧集、RGBA8 和记录的 Alpha／像素摘要。逐帧校验 PNG 结构、CRC、真实尺寸、文件字节及解码像素，不仅信任清单声明。颜色空间保持 `unknown`，不凭空证明跨编辑器色彩保真。

```mermaid
flowchart LR
    M[登记清单与摘要] --> V[字段、时间基与资源门禁]
    V --> F[逐帧 PNG 与像素核验]
    F --> C[复制到新的独立目录]
    C --> R[重新核验复制结果]
    R --> N[后续原生序列导入]
```

## 复制与资源边界

`copy_sequence` 校验成功后才创建目标目录；禁止覆盖已有目录。复制清单与全部帧后再完整核验，失败清理本次新目录，保留源素材。禁止帧符号链接、额外帧、摘要冲突、重复 JSON 字段及错误时长。单次最多一万帧，编码及解码总量各最多 512 MiB；帧率限 1 至 240 fps。资源门禁在图片解码和目标目录创建前执行。
