# FilmCraft 显式序列帧率架构

## 事实源与当前边界

现有 OpenSpec 的 FC-DM-001-SEQUENCE 持有序列交接。本次为原生补丁候选，不能视作已安装运行时。研究源码保持只读；补丁基于固定上游提交导出副本开发。原 CLI 0.2.0-craft.1 锁及标签保持不变。

## 已复现缺陷

原生 `file.importImageSequence` 接受第一张编号 PNG，却使用默认媒体时间基。Effect 12 fps 合成的 12 帧按 30000/1001 fps 导入，只持续约 0.4 秒；把 Film 时间线设置为 12 fps 不会修正源素材。显式帧率测试首先因真实原生帧率错误失败。

## 候选合同

命令增加可选有理 `frameRate: {num, den}`，两个整数必须为正，帧率在 1 至 240 fps 内。原生图片序列按此帧率创建，不修改全局及会话媒体偏好。不提供字段时保留原有偏好行为。公开 Python 素材及 Art 序列合同仍需接入。

```mermaid
flowchart LR
    A[已核验首帧与显式有理帧率] --> C[原生序列命令]
    C --> S[按指定帧率创建 ImageSequenceSource]
    S --> M[媒体时长与实际帧映射]

```

## 构建与兼容性

`runtime/sequence-rate-patch.json` 固定上游提交和组合补丁摘要，包含已发布的字幕字体修复。`build_sequence_runtime.py` 使用摘要门禁构建器生成独立的 0.2.0-craft.2 候选，发布构建前执行字幕和序列组件测试。保留旧归档、用户缓存与研究文件。原生构建不是公开首次安装证据。
