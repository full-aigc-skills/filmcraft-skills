# FilmCraft 公开运行时序列首次使用与 Effect 交接

## 状态与事实源

既有 OpenSpec FC-DM-001-SEQUENCE 是规格事实源。维护版原生 CLI `0.2.0-craft.2` 已公开预发布，源码中的十一项独立技能锁定同一个归档、二进制和来源摘要。旧不可变发布不被覆盖。插件技能快照升级、安装后的验收与 Art 混合交接仍需完成。

## 安装与执行

```mermaid
flowchart LR
    E[单独 Effect 导出技能] --> R[公开原生 CLI 渲染 RGBA 序列]
    R --> S[清单与所有帧摘要]
    S --> F[单独 Film 媒体技能]
    F --> B[真实安装器下载 craft.2]
    B --> I[显式帧率导入与全帧收集]
    I --> V[原生 MP4 与独立解码]

```

测试仅复制对应技能到隔离 `.agents/skills`，从不存在的运行时目录开始，保留真实安装器与公开 HTTPS 下载，校验归档、二进制、PROVENANCE 和版本。单领域测试再调用安装器确认复用。两领域测试消费实际 Effect 渲染结果，没有用静态首帧或人工序列替代片头输出。命令参考从已校验 craft.2 原生目录重新生成，保留每个场景原有筛选范围；命令可查询不代表所有场景已经验收。

## 验收证据

- [公开原生冷安装](evidence/sequence-public-runtime-first-use-20261006.json)：十二帧、12 fps、一秒时长、所有帧收集；移走交付并删除输入后修订成功；原包与技能字节不变；损坏帧拒绝；MP4 独立解码为原片十二帧、移动一帧后十三帧。目标一项通过。
- [Effect 到 Film](evidence/effect-film-sequence-handoff-20261006.json)：分别复制一个技能，空运行时下载两套公开 CLI；实际十二帧透明动画进入 Film；独立解码检查帧数、透明背景透出与图形颜色；Effect 文字修改后移动 Film 包、删除旧片头目录，定向替换成功，背景、初始帧及旧交付保持不变。目标一项通过。
- 更新后的普通音画／字幕／单镜头修订回归一项通过；八项任务技能各自冷安装回归通过；默认源码测试 43 项通过、19 项需要专用环境而跳过。

## 剩余边界

这是源码技能和公开原生运行时的真实首次使用证据。它不证明新的不可变技能与插件已安装，不关闭 Art 序列依赖／选择性修订，不代表完整创作质量、色彩保真、GUI 或全平台验收。任务 4.31 保持开放；当前发布仍是开发阶段。
