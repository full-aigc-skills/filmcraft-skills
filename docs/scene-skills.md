# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `filmcraft-short-video`：短视频粗剪（素材筛选、结构和节奏）
- `filmcraft-interview-edit`：访谈剪辑（多段访谈整理与顺序）
- `filmcraft-subtitle-delivery`：字幕校对与排版（字幕时间、断句与阅读）
- `filmcraft-product-video`：产品展示视频（商品卖点、细节与行动入口）
- `filmcraft-color-match`：镜头颜色匹配（不同镜头的曝光、白平衡和风格）
- `filmcraft-video-export`：视频输出与交付（分辨率、帧率、编码和音频）
